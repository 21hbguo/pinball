# 3D Machine

`pinball_machine.obj` is a deliberately low-poly cabinet made for the MVP opening screen.

Suggested presentation:
- yaw rotation: 8-12 degrees / second
- camera: 3/4 front angle
- neutral dark background
- one soft key light plus blue rim light
- tap transition: camera push toward the front glass, then switch to 2D

Approximate model dimensions:
- width: 1.28 units
- depth: 0.97 units
- height including legs: 2.60 units

The model uses only materials from `pinball_machine.mtl`.
